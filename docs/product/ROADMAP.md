# Purpose

This document defines the strategic development roadmap for HivePlay.
It is organized by milestones rather than dates and evolves as the product matures.

---

# Guiding Principles

- Deliver a usable MVP as early as possible.
- Avoid technical debt that blocks future growth.
- Complete one vertical slice before starting the next.
- Every milestone must produce a demonstrable product improvement.

---

# MVP

## Foundation

Goal:
Create a stable technical foundation.

Deliverables:
- Git repository
- Next.js project
- Supabase project
- Authentication
- Design system foundation
- Database schema
- Initial documentation

Success Criteria:
- Developers can run the project locally.
- CI/CD pipeline operational.

---

## Milestone 1 — Content Management

Goal:
Allow administrators to manage reusable content.

Deliverables:
- Categories
- Questions
- Rich media
- Search & filtering
- Question preview

Success Criteria:
- Complete question bank ready for live games.

---

## Milestone 2 — Game Builder

Goal:
Create reusable game templates.

Deliverables:
- Board configuration
- Teams
- Rules
- Themes
- Question pools

Success Criteria:
- New games can be created without code.

---

## Milestone 3 — Live Gameplay

Goal:
Run a complete game session.

Deliverables:
- Host console
- Audience screen
- Team phones
- Realtime synchronization
- Session lifecycle

Success Criteria:
- Full game playable end-to-end.

---

## Milestone 4 — Polish

Deliverables:
- Sounds
- Animations
- Error handling
- Reconnect
- Session history
- Performance optimization

Success Criteria:
- Production-ready MVP.

---

# Version 1.1

Operational improvements.

---

# Version 2.0

Focus:
Platform expansion.

Potential Features:
- Additional game types
- Audience participation
- AI-assisted content creation
- Tournament mode
- Public template library

---

# Out of Scope

The following are intentionally deferred:

- Payments
- Public marketplace
- Online multiplayer
- Multi-host sessions
- Mobile apps

---

# Release Criteria

Each release must include:

- Documentation updates
- Database migration review
- Security review
- Manual QA
- Version tagging
- Changelog update
